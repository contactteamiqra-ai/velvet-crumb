# VELVET CRUMB

A chocolate atelier portfolio study built with React, Vite, React Three Fiber, Three.js and GSAP.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

The current visual review focuses on hero and cutting. Poly Haven's CC0 Strawberry Chocolate Cake scan now supplies the photographic exterior and PBR maps. Two blade passes precede slice separation, with camera and blade poses driven by the reversible scroll timeline. Local studio lighting, on-demand rendering, product configuration and the demo bag are retained. All runtime assets are local.

**Visual status:** a scan-based review candidate, with strawberries retained. Exposed interiors are authored approximations; physical fracture/contact and an all-chocolate brand adaptation remain outstanding. See [asset production, provenance and reproduction](docs/ASSET_PRODUCTION.md) and [verification notes](docs/QA.md).

Later mixing, baking, frosting and packaging studies are archived in source and withheld from the current presentation until hero/cutting approval. The project is a portfolio demonstration; no checkout or payment is processed.

The existing `wrangler.jsonc` remains compatible with static `dist/` output. Do not deploy or merge this review branch before approval.
